# Profile icons

Seven existing unset.sh icons from Iconoir 7.12.1, regular set, MIT licensed.
The drawings and 1.5 stroke widths are unchanged. A local CSS rule sets
`currentColor` to Onyx (#0A090C) in light mode and Platinum (#F0EDEE) in dark mode.

Source: [the app icon inventory at 0bb11e9](https://github.com/Undefined6799/unset/tree/0bb11e951abf2d6ffdb89b733f66c69837c47e80/shared/ui/icons).
Colours: [brand guidelines at 08ecda2](https://github.com/unset-sh/brand/blob/08ecda2dcdbd8eb44b5262887cc215d501a59db6/guidelines/brand.md).
The original copyright and permission notice is in [LICENSE-iconoir.txt](LICENSE-iconoir.txt).

`repos.json` selects each repository's icon. The renderer accepts only these
bundled names and gives decorative images empty alt text beside visible labels.
Relative image paths follow the README's branch in GitHub previews.
